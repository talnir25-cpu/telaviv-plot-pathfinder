## משימה
פריסה מחדש של פונקציית ה-Edge Function `analyze-plot` ובדיקת התוצאה עבור ויצמן 33 (גוש 6111 חלקה 483).

## שלבים

1. **Redeploy** — הפעלת `supabase--deploy_edge_functions` עם `["analyze-plot"]` כדי לפרוס מחדש את הקובץ `supabase/functions/analyze-plot/index.ts`.

2. **בדיקת בריאות הפריסה** — קריאת לוגים (`supabase--edge_function_logs`) לוודא boot ללא שגיאות.

3. **בדיקה פונקציונלית** — קריאה ישירה ל-Edge Function דרך `supabase--curl_edge_functions` עם הפרמטרים:
   - גוש: 6111
   - חלקה: 483
   - כתובת: ויצמן 33
   
4. **אימות התוצאה** — בדיקה ששטח בנוי מוצע = **1,550 מ"ר** (ולא 1,650 מ"ר).
   - אם התוצאה נכונה → דיווח הצלחה.
   - אם עדיין מחזיר 1,650 → בדיקת לוגים + עיון בקוד `supabase/functions/analyze-plot/index.ts` לאיתור הסיבה (ייתכן שגם הקוד מכיל את הבאג ולא רק הפריסה).

## הערה
אם בשלב 4 מתגלה שהקוד עצמו מכיל את הבאג, אעדכן אותך לפני ביצוע שינוי לוגיקה — כפי שציינת, הקוד "נכון" ולכן לא אערוך אותו ללא אישור.
